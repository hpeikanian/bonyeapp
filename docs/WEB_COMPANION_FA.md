# توسعه مشترک اندروید و وب

پروژه وب در ریپوزیتوری مستقل `hpeikanian/bonye-webapp` نگهداری می‌شود. منبع اصلی صفحات، ترجمه‌ها و API همان `lib/` این پروژه است. پس از هر تغییر قابلیت، کد را با `tool/sync_source.py` پروژه وب همگام و هر دو خروجی را بررسی کنید. خروجی وب همان کد را کامپایل می‌کند؛ قابلیت‌ها جداگانه بازنویسی نمی‌شوند.

گردش کار paired-build با هر تغییر کد در main، خروجی اندروید و وب را با یک نسخه مشترک می‌سازد. برای ریپوزیتوری خصوصی وب، secret به نام BONYE_WEB_TOKEN با دسترسی فقط خواندن آن مخزن لازم است. اجرای واقعی GitHub Actions و انتشار روی هاست باید جداگانه تأیید شوند.

دانلود پادکست با conditional export به فایل بومی یا Cache Storage مرورگر هدایت می‌شود. پخش پس‌زمینه بومی تنها خارج وب راه‌اندازی می‌شود. لینک خرید در وب در همان تب باز می‌شود تا محدودیت popup مرورگر مانع خرید نشود. ظاهر، زبان‌ها و مسیرهای API مشترک می‌مانند.
